# Chapter 04 review: Intraoral Scanners

**Date:** 2026-11-22
**Method:** Subagents could not be launched in this session, so the three checks and the filter were run by one reviewer as four separate, sequential passes. Pass A checked citations, reference details and exact numbers against PubMed. Pass B checked for overstatement (in vitro presented without a label, one study presented as a general rule) and for uncited claims. Pass C checked internal consistency between text, tables, Key Points, Review Questions, the notes file and the three SVG figures. A separate filter pass then re-read each candidate finding against the chapter text, the PubMed abstract and metadata (PubMed connector, 2026-11-22) and the SVG source, and discarded the ones that did not hold up. Evidence comes only from PubMed abstracts and metadata. Full texts were not read.

## Discarded findings

1. **Fig 4.1 and Fig 4.2 bar lengths (Pass C).** This is a false positive. Both figures are drawn to scale once the 4 px rounded bar end is included (see Summary).
2. **Fig 4.3, white semi-transparent rectangle over the left half of the half-arch drawing (Pass C).** This is a design choice that greys out the unscanned half. It does not change the data shown: the four orange teeth match "at least 4 teeth".
3. **4.2.3 "clinicians preferred a powder-free system" [7] (Pass A).** The abstract does not name who preferred it, but the sentence follows the clinicians' preference result. It is a reasonable reading, so it was not confirmed as an error.
4. **4.6 "beyond the usual acceptable range" [17] (Pass A).** This is supported by "both exceeding clinical thresholds". The 120 µm line was correctly left out of Fig 4.2.
5. **4.8 "about 14.5 versus 20.7 minutes" [19] (Pass A).** 14:33 is 14.55 minutes, so the rounding is acceptable.
6. **Table 4.1 descriptions not in the abstracts (Pass A).** They are already marked [UNVERIFIED] and listed in the notes, so this is not a new error. (Finding 5 covers the Key Point that repeats them without the mark.)
7. **Ref 25 has no article number (Pass A).** PubMed lists none either (volume 26, issue 1). This is already noted in the notes file.
8. **Uncited practical guidance (Pass B):** the 4.5.4 scan sequence, the 4.6 Clinical Tip, the 4.7.2 Lab Note and the uncited 4.11 bullets. The notes file already lists them as practical guidance, and no factual error was found. Labelling them as expert opinion is an editorial choice for the author.
