## Discarded findings

1. **Figure 10.2 legend "Orange: corners that cannot be cut exactly" (C20).** This is a false positive. In the SVG source, orange is used only for the two corners in the Design panel (outline circles) and for the uncut fillets in the Leave material panel. Both are corners that cannot be cut exactly. The Overmill panel has no such corners because they are cut away, so it correctly has no orange. One dashed bur per panel is a schematic convention, not an error.
2. **Uncited statements on hard-milled zirconia and on hybrid ceramics needing no firing (A17 hard-zirconia part, C19b, C19c).** These are correct standard statements, and the notes file already records the hard-zirconia sentence as given without data. The ref 20 abstract is consistent with the hybrid-ceramic statement: it studied crystallisation firing only for the lithium disilicate copings. No factual error was found.

Sub-claims removed from findings that were otherwise confirmed:
- B17: the 20–25% shrinkage figure. It is already marked [UNVERIFIED] in the text and notes, as CLAUDE.md requires. Only the "every" wording was kept (finding 17).
- C6: the point that ref 14's abstract is only one sentence. The notes file already records this, and no number is taken from it. "Suspect the tools first" and Review Question 6 are reasonable advice.
- C3: "Ref 7 found leucite glass-ceramic chipped most". This is true (39256107: "IPS Empress CAD the largest"), but the chapter makes no claim that conflicts with it.
- B3: the suggested fix cited ref 7 for "less edge chipping than lithium silicate ceramics". The ref 7 abstract does not support that comparison, so the fix in finding 4 cites ref 8 only.
- A15: the point that ref 19 is "not directly comparable". The chapter already says it used "a different measuring method".
- B12: the point that bur wear was not measured in ref 13. The ref 14 title and the ref 13 keywords address bur wear; only the "trend" wording was kept (finding 15).
- B18: the point that the Table 10.3 strengths are uncited. The notes file records Table 10.3 as general and uncited; only the terminology was kept (finding 7).

## Top items for the author

1. **#4 (major): Key Points "Polymer-containing materials chip less".** Ref 9 in the same section found the lowest 1-mm edge force for a composite block. Ref 10 is about PICN only, and ref 8 is a single four-material cutting test.
2. **#3 (major): "the reference process/method" for milling.** Neither ref 1 nor ref 2 says this, the 10.9 sentence is uncited, and ref 25 found printing comparable for trueness and margin quality. Mark it as expert opinion.
3. **#2 (major): 10.3.3 preparation rules cited to ref 3.** The ref 3 abstract says nothing about tool radius or preparation geometry. Remove the citation (the notes already treat it as a general CAM principle).
4. **#1 (major): "5-axis is the most accurate".** It rests on one sentence in a narrative review with no comparative data. Key Points adds "for complex work", which the source does not say.
5. **#11 and #14 (minor): fine and extra-fine modes.** The surface-quality claim and Review Question 4 rest on a zirconia study of slow, normal and fast protocols. Ref 6 shows only higher bur wear for extra-fine mode, with no strength benefit, so it does not support "use finer modes for delicate areas".
